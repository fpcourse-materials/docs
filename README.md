# FP course materials

Use `make slides` to build slides.

Use `make fp2` to build the FP2 notes. To inspect a page as an image, run `make fp2-page PAGE=43`; the PNG is saved to `out/fp2/page-43.png` (requires Poppler).

Use `make fp2-students N=4 S=4` to build `fp2-ch1-4.4.pdf`: chapters 1–3 and chapter 4 through “Всё через свёртки”, including its Visitor example.

There are IntelliJ configurations to build slides also.
